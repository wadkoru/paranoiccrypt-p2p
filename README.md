# ParanoicCrypt P2P

Приватний P2P-месенджер: пряме WebRTC-з'єднання між браузерами, без сервера,
без реєстрації. Один файл `index.html`, працює офлайн після першого відкриття.

- **Один на один** — найпростіше й найанонімніше: лише два пристрої, жодного реле.
- **Колективний дзвінок** — голос/відео й текст для кількох людей одразу (mesh,
  без сервера: нові учасники «знайомляться» з рештою через вже встановлені
  зашифровані канали).

Шифрування: ECDH P-256 → HKDF → AES-256-GCM, поверх нього ChaCha20-Poly1305
з окремим ключем (перевірено проти OpenSSL і RFC 8439). Повідомлення доповнюються
до «кошика» розміру, щоб приховати точну довжину. Код звірки (SAS) підтверджується
вголос перед початком розмови — захист від підміни з'єднання.
